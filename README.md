# Hereditary federated learning workshop 6
Workshop 6 will focus on federated clustering. There are two folders:
- `clef-kmeans-unfederated`: This folder contains code to run centralized KMeans on the BRAINTEASER dataset, and includes data visualization scripts.
- `fed-kmeans-flower`: This folder contains a Flower implementation of federated KMeans.

See the individual folders for the required setup.

More information on the workshop and the schedule can be found on this [page](https://hereditary.dei.unipd.it/wiki/doku.php?id=groups:federatedlearningworkshop6) on the collaborative platform.
