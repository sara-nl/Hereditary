# Messaing API example 

This is a simple example of how to use the Flower Messaging API to implement a federated learning /analytics application.

## installation
Create a venv and install dependencies:
```bash
python -m venv messagin_api_venv
source messagin_api_venv/bin/activate
pip install -e .
```

If you extend this and add any dependencies, add them to the pyproject.toml file.

## Running the example: 
run the following command: 
```bash
flwr run .
```
