This folder contains the unfederated K-means implementation for the CLEF data and example scripts

If you would like to run the data, download it [here](https://mega.nz/file/05wQlACa#IWL1MDrAQF1MJTBtSZLpn_ziE7e5EPbW81RUz2j4LoQ), extract it and set the CLEF_DATA_PATH_UNFEDERATED environment variable to the path of the extracted data like so:

export CLEF_DATA_PATH_UNFEDERATED="/path/to/extracted/data/retrospective/ALS/CSV/data/datasetC/"
